L-System for Procedural Road Generation
#####################
:Contributor(s): Kayla Han
:Instructor: Dr. Sarah Abraham
:Class: CS 370
:School: University of Texas at Austin
:Course: Undergraduate Reading and Research
:Tools used: Godot 4.0, C#

This repository holds files for an ongoing independent study by Kayla Han and supervised by Dr. Sarah Abraham. The study focuses on exploring procedural generation using an L-system to generate a series of symbols based on a set of rules. Based on environmental data, the system then generates road patterns to satisfy certain goals such as trending toward population density. Roads follow rules such as trending toward population densities defined by the environment and position relative to terrain. Based on terrain data, roads can select to generate as either a regular road that conforms to the surface, a bridge over gaps, or a tunnel through terrain.

These files are contained within a Godot project and can be opened using Godot 4.0.
